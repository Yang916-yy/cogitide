# Research mechanisms and publication acceptance

Historical publication record dated **2026-10-30**, public name Cogitide with Workbench assembly/data compatibility. Raw local evidence stays out of Git; scripts and frozen fixtures remain reproducible. These are engineering implementations, without proved academic novelty or paper effect reproduction.

Implemented slices were ACON versioned compaction guidelines/observation projection/source appendices and explicit paired optimization; RepoMem/DCI frozen Git ancestry, keyword/cochange search and raw source navigation; GEPA training feedback mutations, per task Pareto candidates, weighted parents and bounded merge; SkillOpt bounded edits with stricter per task nonregression; Speculative Actions one exact read only predicted file read; and existing ACE/APC sourced incremental procedure candidates. Full dual compressors/distillation, learned semantic graphs, complete author harnesses/crossover, Sleep/meta skills, write speculation, full ACE roles and autonomous continuous learning were excluded. Gaia2 inspired dynamic failure fixtures rather than being an installed algorithm.

Runtime research options default off and freeze versions/base commits at task start. The historical counts changed from seventeen/eighteen tools when history was enabled, or twelve/thirteen in read only. Offline skill/guideline optimization requires explicit CLI `--execute`; validation only requires no keys/actions. Real AgentEngine/official SDKs use a fixed commit, isolated workspace, trusted frozen validation and protected path hashes. Cross split families/identical payloads are rejected; selection/holdout cannot enter proposal diagnostics. Final test results never choose candidates. Exports never activate themselves.

Every inference/summary/proposal counts toward observed usage. Budgets stop between operations and cannot undo in flight usage; missing usage/cost is unknown, not free. Cancellation retains a terminal record. The runner is an application permission boundary for trusted scripts, not an OS sandbox.

Historical strict .NET 11 RC3/C# 15 build had zero warnings/errors and **481/481 regression tests passed**. Five real stdio/local SSE integration groups passed; lifecycle/tools/research were rerun after final command snapshot repairs. GEPA/SkillOpt each performed **six evaluations/sixteen counted calls**; ACON performed **four actual summaries** and paired/final holdout evaluation. Aggregate was **68 local requests, zero external calls**. Packages contained **344/340/340 files**, with SHA-256/native architecture/locks/licenses checked. Windows packaged Host ran using its own runtime; Linux/macOS were structure only.

Retained review failures covered forged holdout IDs in development diagnostics, Windows cross drive export rejection, cancellation after final holdout, growing file hash bounds, read only Git object cleanup and DLL lock/build concurrency. Deterministic Windows evidence reproduced `File.Move(overwrite)` sharing failure and validated `File.Replace`; transient missing/sharing reads received at most **310 ms** cancellable retry. Permanent/corrupt state stayed errors and commands were never retried. The original external lock holder was not identified and was not attributed to antivirus. Failures were not rewritten as passes.

Original code remains Apache 2.0 with Pi/OpenCode MIT and Codex LICENSE/NOTICE retained. A checksum verified **Gitleaks v8.30.1** scan of staged source reported no leak for this historical publication; it was not a guarantee about future changes. Independent same model/budget/repository family experiments are still needed for success, intervention, cost per success, context/cache overhead and latency. Local candidate wins do not establish those benefits. Historical evidence paths are local ignored artifacts; public users should rerun scripts or inspect independent CI reports.
