# Compaction, project reuse and composer acceptance

Historical validation dated **2026-10-30**, when the internal name was Cogito. This stage still had a separate official Codex app server route; later unified kernel changes supersede that architecture. All tests in this round ran in the background without opening the desktop.

Pi/OpenCode inspired whole tool group compaction, verbatim user instructions, recent suffixes, SHA-256 checkpoints and durable raw history were integrated with scoped AGENTS.md reload, YamlDotNet 18.1.0 skill discovery and project procedure candidates. Approval rechecks changed rules; summaries cannot commit after failure/cancellation or remove required original instructions. The composer placed attachments/permissions/model/reasoning controls below input with send/stop and Ctrl+Enter steering. API execution modes were application tool policies, never OS isolation.

ACE incremental entries and APC conditional plan reuse motivated experience storage, without full ACE roles, learned retrieval, global graphs or GEPA. Candidates retained source/version checks and could not become universally valid knowledge. Fixed Pi `e7a0df27c09d11bf4161d3605246cbf57a129cb2` and OpenCode `60072747957926e7aeec7e911fe6e23abe9bf830` mappings/notices remain in provenance; .NET records/JSON/cancellation and existing SQLite supply infrastructure.

The historical strict build reported **zero warnings/errors** and **239 passed, one explicitly gated Codex handshake skipped**. Real Host continuity fixtures reported **seven summaries, 32 original messages, 28 requests and eleven checks**; Host tools and seven lifecycle categories passed. Actual Desktop assemblies were rendered Headless in both languages, without GUI/IME/scale acceptance. Official Codex image/effort/sandbox parameters were protocol fixtures, not actual account or OS sandbox verification.

An explicitly authorized real DeepSeek continuity check used **three requests, 8.114 seconds, 11,897 input/771 output tokens**, one summary and one file read, preserving 34 original messages and ending with 38 in an isolated generated database copy. A CRLF/LF comparison first falsely failed; the failure was retained and existing responses were rechecked offline without another model call. This is controlled functionality, not autonomous coding success.

Historical preview packages contained **318/314/314 files** for win-x64/linux-x64/osx-arm64 and passed hashes/locks/licenses. Windows packaged Host ran without GUI or model calls; Linux/macOS only had structural checks. Limits included character rather than exact token budgets, finite run limits, unreplayed unknown/queued actions, local skills only, images rather than general document uploads, 64 recent sessions/128 experience candidates and unpaged underlying event reads. No fixed budget success/cost/latency or competitive gain was established.
